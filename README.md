# microbiomemag


- My entire metagenomics analysis pipeline. 
- QC, Host assembly removal, assembly, mapping, binning, refinement, checkm( Groom), gtd, annotation.
- Edit the config file at the top to highlight your configuration. 

```
  bash microbiomemag.sh

```

- It will produce the following folders. 

```
00_qc
01_hostfree
02_assembly
03_mapping
04_binning
05_refine
06_checkm
07_gtdbtk
08_annotation
logs

```
